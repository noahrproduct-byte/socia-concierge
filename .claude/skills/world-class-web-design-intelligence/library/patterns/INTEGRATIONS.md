## Recommendation for SOCIA
- **Settings → AI Assistants:**
  - List SOCIA's MCP tools with read or posting badges.
  - Add 4–6 example prompts with copy buttons.
  - Keep the "Can publish posts" switch per connection.
- **Settings → Connected accounts:** explain what each connection type unlocks (for example, Instagram via Facebook vs Instagram Login).
- **Connect buttons** use neutral styling with the platform mark, not brand-coloured walls.
