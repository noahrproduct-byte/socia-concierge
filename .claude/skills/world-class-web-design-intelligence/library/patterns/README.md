# Pattern comparisons

One file per tag (for example `NAVIGATION.md`), created the first time a reference contributes a pattern to it. Each file compares the approaches across references for that problem area:

```markdown
# NAVIGATION

## The problem
What SOCIA needs from this area, in one or two lines.

## Approaches seen
### <Product A>: <approach in a phrase>
What it does · why it works · cost or trade-off · [measured/observed/inferred]

### <Product B>: …

## Comparison
Where they agree (a recurring principle), where they differ, and which principle best serves SOCIA's problem, and why.

## SOCIA today
What SOCIA does now and the real gap, if any.

## Recommendation
The approach to adapt, in SOCIA's design system, or "no change: SOCIA's current solution holds up".
```
