# Editor bugs: found, reproduced, fixed

The bug pass of 2026-11-12 on the Content Studio video editor (`components/studio/ClipBuilder.tsx` and what it uses). Method: `npx tsc --noEmit`, `npx eslint .`, `npx vitest run` and `next build` on `origin/main` (all green at the start, so every bug below is a runtime one), then every flow exercised in the dev lab (`/dev/studio-lab?screen=editor`, `build-collect`) with the browser console and the server log open, plus a line-by-line read of the data path (upload, save, export) and the rendering path (composition, timeline, text). Regression tests live in `lib/studioClips/editorBugs.test.ts` unless another file is named.

Live test on sociaos.com (2026-11-13, the owner's account): four clips uploaded at once (one HEVC .mov converted to H.264 on the device, two silent B-roll, one with sound), the Talking Head theme applied, medium stabilization made on the server in under a minute, the cut saved and exported: the file passed SOCIA's own inspection (3 joins, sound at -17 dB) and was saved as a draft post. Second pass: both clips with sound transcribed through the new route (36 and 18 words), Bold Hook pulled "Called The Agency with over 124,000 stars on GitHub" to the front with captions on and one B-roll overlay, and the export passed again (1 join, sound at -25 dB).

Not fixed, noted for the owner:

- `studio_builds` is service-role only since `supabase/studio-cut-meter.sql`; a deployment without `SUPABASE_SERVICE_ROLE_KEY` fails every build read with a generic 500. Documented in ARCHITECTURE.md.
- Two concurrent brief POSTs can pick the same `opportunity_idx` (`nextBriefIdx`); rare, needs a DB-side sequence.
- Remotion's `<Img>` logs "The source image cannot be decoded" once per text line when the Player swaps a line's PNG while a decode is in flight; harmless, the line draws.
